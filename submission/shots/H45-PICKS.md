## How to shoot them again

The sim decides the frames. For a later package with the same sim:

```
powershell -NoProfile -ExecutionPolicy Bypass -File tools\qa\eye9\eye9-run.ps1 -Exe <copy>\Windows\ThirdJam\Binaries\Win64\ThirdJam.exe -Run p-playnow-rookie -Level rookie -ScriptHuman 2 -Every 400 -StartEvery 10 -Frames 8460 -Dense "0:150:10,1112:1136:1,1706:1730:1,1874:1898:1,2996:3020:1,8300:8322:1,8380:8460:10"
python tools\qa\eye9\walk2.py playnow-rookie glass-house arsenal fog-of-war pond
python tools\qa\eye9\deliver.py tools\qa\eye9\out "" h46 submission\shots
```

(the copy must stand under the worktree; the game runs off screen, no window, no cursor; the driver starts it with no API key and no CLI on its
PATH). The booth's line, the plate beside the score and the goal's dust are not on the sim's seed: read the quoted lines again from the new frames.
A package whose sim, brain or cartridges changed plays other matches: pick again from whole films (`walk2.py`, `look.py`, an eye).
