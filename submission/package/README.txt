HOKEJ
Rough hockey for clay skaters.  You skate.  The mouse is your stick.  You hit people.

HOW TO START
1. Unzip the whole folder somewhere you can write (Desktop or Documents is fine; not inside Program Files).
2. Run ThirdJam.exe.  (ThirdJam is the game's internal project name; the game on screen is HOKEJ.)
3. First launch compiles shaders for a few seconds.  Then the menu.  PLAY NOW starts one match at the level that is lit.
   ROOKIE is the newcomer's level, PRO is for anyone who has played a hockey game, ALL-STAR is the wall.

WHAT YOU NEED
- Windows 10 or 11 (DirectX 12) only, 64 bit, with a graphics card that does DirectX 12.  Under 450 MB of disk when unpacked.
- The Microsoft Visual C++ runtime (x64).  Most PCs have it.  If ThirdJam.exe closes at once or complains about
  a missing VCRUNTIME / MSVCP dll, run this once, accept, and start the game again:
      Engine\Extras\Redist\en-us\vc_redist.x64.exe

THE WINDOWS FIREWALL PROMPT
The first time you run the game from a new folder, Windows may ask whether HOKEJ may access public and private
networks.  The game opens a network socket at start for its two-player mode (PLAY WITH A FRIEND).
Solo play does not need network access.  Choose Allow if you want to play with a friend.

CONTROLS (keyboard and mouse)
  W A S D / arrows   skate (S against your motion is a hard brake: stop, cut, go)
  Mouse              aim the stick (the blade follows the cursor on the ice)
  Left mouse         with the puck: shoot (hold to lift it, let go to fire)
                     without it: cross-check, a shove off the puck (hold to brace)
  Right mouse        with the puck: pass to the mate your stick points at (hold for power)
                     without it: body check (head-on at speed is the big one)
  Middle mouse       cross-check (or mouse button 4)
  Q                  pass (hold for power)
  F                  your ability, when a mode or a pickup gives you one
  E                  spin off a check
  Mouse wheel        deke
  Space              poke: jab for the puck (about one jab in ten takes it)
  Shift              sprint, while the legs last (the panel's SPRINT row dims when they are spent)
  Ctrl               brake
  Esc                pause: resume, change a rule, controls
  R                  restart the match
Gamepad: left stick skate, right stick aim, RT shoot (without the puck: cross-check), RB pass (without: check),
LB cross-check, X pass, R3 ability, B spin, Y deke, A poke, LT sprint, Start pause.
The pad is mapped; no person has play-tested it yet.
A panel at the bottom left shows the keys you need now, with or without the puck, all match.
To remove it for good: SETTINGS, CONTROLS PANEL, OFF.
Any key can be rebound under CONTROLS (in the menu, or Esc in a match).

THE SHORT VERSION OF THE RULES
No whistle (one mode, Glow Ice, keeps it).  Hits obey momentum: beside a skater at his speed a check
is a nudge; head-on at full speed flattens.
If you carry the puck you cannot check.  Stop five stick lengths short of a defender, cut, go.
Five a side, and your mates pass.  Once per period CHANGE A RULE (Esc) moves one slider.

CREDITS AND TOOLS
This game was made for the Third Jam with Unreal Engine 5.9.  On RTX graphics cards it uses NVIDIA DLSS
technology (upscaling, on by default).  The code, the tests and the dev log were written and run
by AI coding agents directed by the team.  AI-generated content (images, 3D skater meshes, voice and sound effects) is
declared as such and is not claimed as sourced.  The tools are named on the game's CREDITS screen.

HOKEJ is a work of fiction played by clay figures.  No real teams, players or brands appear in it.
