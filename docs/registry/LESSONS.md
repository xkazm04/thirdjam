# The jam's lessons, as a ledger for the registry's game-production domain

Lane R, package R1, 16 Nov 2026. Forty lessons, grouped by where each lands in the registry. Every lesson is written as
"when X, do Y, because Z" with no project, product, engine or tool name in it; the project's names live only in the evidence
column. "Nearest" is a path under `knowledge/<domain>/`, found by querying the domain's `index.json` (never read whole) on the
registry checkout as it is on this machine (169 commits behind its remote: see STATUS, "unsure"). "Lead" says whether the
lesson was filed in `thirdjam/.ai/registry-leads.jsonl` (filed = earned: it came from a change that landed in the jam's repo and
was verified there) and, when not, why.

Kinds: **new technique** (under an existing subject), **application** (an existing technique or law, realized here), **amendment**
(a sentence or rule added to an existing technique), **new subject** (one of the draft specs), **other domain** (named).
Confidence is about the claim transplanting to an unrelated team, not about the jam's figure, which is measured in every row.

Short names in the evidence column: `R-00nn` = `contracts/RULINGS.md`; `A.md` = `status/A.md`; `A2nn` = `status/A2nn.md`;
`BAR` = `docs/experiments/BAR.md`; `TRUTH` = `submission/TRUTH.md`; `EC` = `briefs/EVOLUTION-COMMON.md`; `NC` =
`briefs/NIGHT-COMMON.md`; `LOG` = the Director's skill improvement log (third-life `.claude/spark/config.md`); `MEM` = the
Director's feedback memory files.
