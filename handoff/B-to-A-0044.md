## What B reads in it (A owns the call; this is a proposal from the code as it is on main e1ddfe0c)

Today: the controls strip shows 8 s in the first match of a session only (`UJamHudWidget::ControlsHintFrames` = 480, `ControlsHintSpent`,
`jam.hud.HintEveryMatch`), plus the bottom-left pill `ButtonsBadgeLine` (what LMB / RMB do right now). He wants one panel, better looking, always there.

1. **Always visible**: in every match, all match, while playing (hidden on the pause card, the goal banner and the end card, which have their own).
2. **A SETTINGS row** `CONTROLS PANEL   ON / OFF` (default ON), saved with the other settings (`FJamSettings`), so OFF stays off across sessions.
   The CONTROLS screen and the pause card keep the full table either way. The 8-second strip goes away (the panel replaces it); the pill
   either merges into the panel or stays as is when the panel is OFF (your call).
3. **Live and by possession** (the code already knows both: `UJamInputMap` bindings, `IsPadLast()`, `JamControls::HasPuckForButtons`):
   - with the puck: `LMB  SHOOT` (hold = harder), `RMB  PASS` (hold = power), `WHEEL  DEKE`, `E  SPIN`;
   - without: `LMB  CROSS-CHECK` (hold = brace), `RMB  CHECK`, `SPACE  POKE`;
   - always: `WASD  SKATE`, `SHIFT  SPRINT`, `CTRL  BRAKE`, `F  ABILITY` (only when one is held);
   - the pad's glyph names when the pad was touched last (RT, RB, A, ...), the rebinds as rebound. Six to eight rows at most: the
     possession half swaps on the frame possession changes, with a short fade (6 frames), so a person learns "now I have it, now I don't".
4. **Look** (the menu's own style, `MenuStyle.h`, one product): a dark translucent panel (black at ~55 %, the menu's corner radius), bottom-left
   above the safe margin, never over the radar or the score; each row a keycap (a light rounded box with the key's short name in the menu font,
   ~22 px tall at 1080) and the verb in caps beside it; the possession half headed by a small team-coloured dot (blue / orange) so the swap is
   seen; the held-verb row lights while its button is down (the words already swap at the hold: shoot -> slap, pass -> saucer, cross -> brace).
   Width at most ~300 px at 1920 x 1080; it scales with the HUD. The commentary strip keeps its place above it (`CommentaryStripY` today
   steps over the strip for 8 s: it would step over the panel always).
5. **Not in the picture**: no logos, no real controller art; key names only.

If A wants keycap art from B (a 9-slice keycap texture, a pad glyph sheet), say so and B makes it under `Game/Plugins/JamAssets/Content/UI/`.
