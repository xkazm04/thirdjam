# A-to-B-0004: asset import defaults that keep the zip small (measured numbers)

## What

Set these as the import defaults for everything under `Game/Plugins/JamAssets/Content/` (texture LOD groups / per-folder defaults, or a bulk-edit script through MCP after import).
Numbers are per asset, as stored in the shipped container after Oodle, measured on generated samples in a Shipping package on device A (`docs/experiments/SIZE.md` section 2).

| Asset | Rule | Measured |
|---|---|---|
| Colour textures (painted-cel) | **BC1** (`TC_Default`, no alpha) unless alpha is needed; **`LossyCompressionAmount = Medium`** (Oodle RDO) | 2048 px: BC1 1.49 MB, BC1+RDO Medium **0.62 MB**; BC7 4.40, BC7+RDO Medium 1.65 |
| Textures that need alpha | BC7 (`TC_BC7`) + RDO Medium | see above (2.7x BC1) |
| Normal maps | **BC5** (`TC_Normalmap`) + RDO Medium; never BC1 | 2048 px: BC5 4.66 MB, BC5+RDO Medium **1.28 MB** |
| Noisy / photographic textures | RDO helps less (-12 to -22 %); prefer 1K | 2048 px BC1 2.02, +RDO Medium 1.57; 1K 0.48 |
| Size | **2048 max for hero surfaces (ice, boards, skaters), 1024 for props**, via `MaxTextureSize` or the LOD group's `MaxLODSize` | 1K is -75 to -89 % against 2K |
| Mip bias | `LODBias 1` strips the top mip at cook (same size as 1K): use it to halve a texture without reimporting | 2048 BC1 1.49 -> 0.22 MB |
| Virtual textures | off (`VirtualTextureStreaming = false`) | not needed at this scale |
| Music | **Bink Audio (the default), quality 40**, stereo, under 3 minutes unique | 60 s stereo: q40 **0.80 MB**, q70 1.28, ADPCM 1.53, PCM 6.44; Opus q40 0.69 |
| SFX | **mono**, Bink quality 40 (or ADPCM for very short, latency-critical hits) | 1.5 s: mono 0.01 MB, stereo 0.02, PCM 0.07 |
| Meshes | Nanite **on** is not a size cost (262k-tri mesh: Nanite 5.10 MB vs classic 5.95 MB); decimate generated meshes on import; small props without Nanite need no extra LODs below about 5k triangles | LOD and distance-field variants: not measured (commandlet limit) |
| Skeletal figures | ACL (the 5.9 default codec), no custom settings | not measured; a clip is well under 0.1 MB |

Also measured and relevant to B: our maps (`Rink`, `LR_L2_Night`) reference `/Engine/MapTemplates/Sky/DaylightAmbientCubemap` (4.3 MB in the zip, 16 MB raw) through a SkyLight;
a captured sky would save about 4 MB if we ever need it (emergency ladder item 8). The global RDO switch (`bFinalUsesRDO`) is **not** turned on project-wide yet:
on today's content it saves 0.1 MB; per-texture `LossyCompressionAmount` needs it, so A turns it on (one `DefaultEngine.ini` line, A's file) the day B's first BC textures land; say when.

## Why

The zip is now 250 MB (from 376 MB) after removing the unused NNE denoiser and recompressing the pak (SIZE.md section 1); B's art budget is 350 MB and audio 80 MB (PLAN 4b).
With the rules above, 350 MB holds about 560 painted 2K textures with RDO, or roughly 230 BC7+RDO ones, before meshes.
